## 1. 이머징 샷건 (Emerging Shotgun) — Biberion

**출처**: YouTube "The Trader Who Got Rich By Being 'Scared'" (Billionaire Bears, 2026-01-27, 38분, vid=SkWbFhKSA0I). 일본 2ch 시대 데이트레이더 Biberion(ピペリオン, cis·BNF와 동시대) 실화 기반 **연출 다큐** — 세부는 각색·반(半)전설이므로 사실보다 **방법론 가설**로만 취급.

### 1-1. 핵심 철학 (리스크 우선)
- **"우량주도 0까지 갈 수 있다"** — 펀더멘털 좋아도 떨어지는 종목에 **물타기 금지**(2000년 오리코 −76% 교훈). 펀더멘털이 아니라 **가격 움직임**으로 매매.
- **공매도·신용 안 씀, 현물만, 타이트 손절, 작은 베팅.** "겁 많은 성격"을 엣지로 — 손실 회피가 규율이 됨.
- 단순함이 강점 — 복잡한 멀티섹터 리딩(BNF식)으로 갈아타려다 오히려 무너짐 → **자기 엣지 영역 고수**.

### 1-2. 메커니즘 (파라미터화)
| 단계 | 규칙 | 시스템 파라미터 후보 |
|------|------|--------------------|
| **레짐 게이트** | 이머징/소형주 지수의 5일·25일 이평 **골든크로스** + **거래량 동반** | `ma_fast=5, ma_slow=25, vol_confirm=True` |
| **진입** | 크로스 형성 후 5분 내 **이머징 소형주 ~10종목 동시 매수**, 업종 분산 | `basket_n≈10, sector_spread=True, entry_window=5min` |
| **손절** | 전 종목 **매수가 바로 아래 타이트 스톱** | `stop=tight(entry-εATR)` |
| **익절/피라미딩** | 손절 다수 OK — **1~3종목만 터지면 수익**. winner는 **불타기**로 비중 증액 | `pyramid_winners=True` |
| **보유기간** | 데이트레이드 또는 1박 | `hold=intraday~1d` |
| **부가 셋업** | TOPIX 지수 편입 예정주 선취매(인덱스펀드 강제매수), 외국인 기관 발표 선취매 | (이벤트 드리븐) |

### 1-3. 작동 전제조건 (= 백테스트 필터)
1. 이머징 개별주가 **지수를 따라** 움직일 것.
2. 종목들이 **함께(동조)** 움직일 것 — 하나 오르면 다 오름.
- → **횡보/레인지장에선 작동 안 함**(2004 레인지장서 전략 붕괴). **변동성·추세장서 강함**(2008 변동성장서 2개월 ~3배). 즉 **명백한 regime-dependent 전략**.

### 1-4. 우리 시스템 매핑
- **레짐 게이트(5/25 크로스 + 거래량)** → `engine/chart/read.py` 컨플루언스에 이미 볼륨·추세 탐지기 존재. "지수 크로스 + 종목 동조성"을 **regime 필터**로 추가 가능.
- **바스켓 + 타이트 손절 + winner 불타기** → AI Swing 전략의 **Kelly·Heat·Pyramid 레이어와 동형**. "10종목 분산 + 1~3개만 터지면 OK"는 **양의 비대칭(positive skew) 바스켓 모멘텀**.
- **"지수-개별주 동조성"** → cross-sectional 상관/베타 필터로 정량화(동조성 높을 때만 진입).
- **물타기 금지·타이트 스톱** → 기존 kill_switch·리스크 규율과 정합.

### 1-5. 검증 가설 (falsifiable — 백테스트로 깰 것)
- **H1**: 소형주 유니버스에서 "지수 5/25 골든크로스 + 거래량 스파이크" 직후 분산 바스켓 진입 + 타이트 스톱 + winner 피라미딩이, 추세/고변동 레짐에 한해 양의 기대값을 낸다.
- **H2**: 동일 전략이 레인지/저변동 레짐에선 손절비용으로 음의 기대값 → **레짐 필터가 edge의 핵심**.
- **H3**: "지수-개별주 동조성"이 높은 구간으로 제한하면 샤프가 유의하게 개선된다.
- 측정: walk-forward OOS, PBO/CSCV로 과최적화 점검(재무관리 trader 신뢰도 4툴킷 재사용). 한국 코스닥/소형주 + 미국 러셀2000/스몰캡으로 cross-market 재현 확인.

### 1-6. 한계·주의
- 연출 다큐라 **생존자 편향**(성공 사례만 전설화) + 세부 수치 각색 가능 → 사실로 인용 금지, **가설로만**.
- 단일 인물 일화 = 샘플 1. 자기 엣지 영역서도 레짐 바뀌면 무너졌음(2004·2006). **레짐 의존성이 양날의 검**.
- 우리 검증 결과(MEMORY): 순수 기술지표 mean-reversion 66.6% 한계 — 이 모멘텀/샷건도 **검증 전엔 라이브 금지**.

### 1-7. 백테스트 결과 (2026-06-18, `scripts/shotgun_walkforward.py` → `out/shotgun/shotgun-walkforward.md`)
일봉 프록시·**full-sample concept screen(롤링 OOS 윈도우 없음 — in-sample REJECT은 OOS로 못 살리므로 결론 유효)**·현재 S&P600 소형주 579종(**생존편향**)·IWM 5/25 **크로스이벤트** 진입·**다음봉 체결**·**true daily MTM**·1261트레이드:
- **샷건 SHAPE는 재현됨**: 승률 35%인데 per-trade EV **+0.22%**, 페이오프 **2.01x**(avg win +7.15% vs loss −3.55%, 소수 winner가 캐리 — 다큐 그대로).
- **H1 PASS**(트렌드 EV>0) / **H2 FAIL**(choppy ≥ trend — 다큐 핵심인 "추세장 의존성" 불성립) / **H3 directional+**.
- 포트: CAGR +0.81%·Sharpe **0.17**·MDD −19.4%(대부분 현금). **IWM(0.59)·SPY(0.86)·생존편향 EW 소형주(0.84) 전부에 열위.** 포트폴리오 엣지 없음.
- ⚠️ **무결성 노트(codex 적대적 리뷰 3라운드, 버그/룩어헤드 4건 적발 — 매번 Sharpe 하락)**: 진짜 Sharpe **0.17**이 누적 버그로 가짜 **2.41**까지 부풀려졌었음. ①동시성 캡을 보유일 단위 적용(슬롯 차면 초기일 건너뛰고 나중에 원래 진입가로 계상=불가능 체결) 2.41→0.67 ②`ret/hold`를 보유 이전일에 분배=룩어헤드 스무딩(변동성 과소·Sharpe 과대) 0.67→0.26 ③진입을 ma5>ma25 전 구간이 아닌 **크로스 이벤트**로 한정 + 시그널 당일 종가가 아닌 **다음 봉**에 체결(EOD 룩어헤드 제거) 0.26→0.17. **교훈**: 동시성 캡은 진입에서 enforce / 일별 P&L은 가격경로에서(총수익 분배 금지) / 당일 종가시그널은 다음봉 체결 / 상태 게이트와 이벤트 트리거 구분.
- **VERDICT: REJECTED, 자본 미배선.** 다큐 엣지는 일봉 바스켓으로 재현 안 됨(per-trade 비대칭 SHAPE만 존재). 살리려면 = PIT 소형주 멤버십 + 상폐수익 → PBO/DSR → intraday/피라미딩 충실 모델. (연구 원장 `STRATEGIES.md` 등재)
- **메타 교훈**: 최초 "Sharpe 2.41 = 좋은 전략!"은 거짓양성이었고, 자기검토(생존편향 플래그)는 잡았지만 4건의 백테스트 버그는 **codex 적대적 리뷰만이 잡음**. 백테스트는 "좋아 보일수록 더 의심" + 외부 적대검증 필수.

### 1-8. PIT 검증 시도 + 무료데이터 한계 (2026-06-18, `out/shotgun/shotgun-pit2019.md`, 유니버스 `data/universes/sp600-pit-2019.csv`)
현재-구성종목 생존편향을 줄이려 **S&P600 멤버십을 2019-06-22 시점으로 동결**(Wikipedia 리비전 903017102 파싱, forward-selection 편향 제거)하고 forward 검증:
- **무료데이터 한계 확정**: 2019 멤버십 993종 중 **319종(32%)이 2026까지 상폐 + yfinance에 가격 이력 전무**(AKRX 파산·JCP·CHK·ENDP·FTR·X 등 = 바로 그 패자들). Yahoo는 생존자+최근상폐만 보존. → **무료로는 survivorship-free 소형주 검증이 구조적으로 불가능**(상폐 tail이 복구 불가).
- **2019-동결 생존자(692) 결과**: per-trade EV +1.04%·win 33%·payoff 2.85x·**H1+H2 PASS**(레짐의존성 이번엔 성립). 하지만 포트 Sharpe **0.48**·maxDD −13%(대부분 현금) → **IWM(0.56)·SPY(0.89)·생존편향 EW(0.78) 전부에 여전히 열위**. REJECTED.
- **이 0.48조차 319 상폐 종목을 누락**(타이트스톱은 상폐 갭다운에 취약 → 포함 시 더 하락). 두 검증(현재구성 Sharpe 0.17, 2019동결 0.48) 모두 결정적 REJECTED.
- **진짜 PIT엔 유료 데이터 필요**: CRSP(학술, 상폐수익 포함) / Norgate Data(~$65/mo, 미국 상폐주+델리스팅) / Nasdaq Data Link Sharadar SEP(~$50/mo, survivorship-bias-free). 무료 경로로는 여기까지가 한계.
